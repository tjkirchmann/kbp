# Add Precommit Hooks for Linting

## Context

The KBP monorepo currently has **no working lint/format tooling**. The backend
(`src/backend`, Python 3.12 / FastAPI, 103 `.py` files) has no linter or
formatter configured at all. The frontend (`src/frontend`, Vite + React 18 + TS,
62 `.ts/.tsx` files) has a `"lint": "eslint ."` script in `package.json`, but
ESLint is **not installed** (absent from `devDependencies` and the lockfile) and
there is no ESLint config — so the script fails. There is no `pre-commit`
framework, no `.pre-commit-config.yaml`, and no CI.

This change introduces pre-commit hooks that lint and format the whole
repository, giving consistent style enforcement on every commit across both the
Python backend and the TypeScript frontend.

---

## Goals / Non-goals

- **Goal**: A repo-root `.pre-commit-config.yaml` orchestrating linting +
  formatting for both `src/backend` and `src/frontend`.
- **Goal**: Ruff (lint + format) for Python; ESLint + Prettier for the frontend.
- **Goal**: A `make lint` entrypoint and brief docs in `AGENTS.md`.
- **Non-goal**: CI / GitHub Actions (no `.github` exists; out of scope).
- **Non-goal**: `mypy` / type-checking as a hook (TS already typechecks via
  `tsc -b` in the build; Python type-checking is a separate future effort).

---

## Approach

Use the **pre-commit** framework (pre-commit.com) as a single cross-language
orchestrator. Hooks run on staged files at commit time; `make lint` runs the
full-repo pass (`pre-commit run --all-files`).

Decisions (confirmed with user):

| Area | Tool | Why |
|------|------|-----|
| Python backend | **Ruff** (`check --fix` + `format`) | Fast, single tool; replaces flake8/isort/black |
| Frontend TS/React | **ESLint + Prettier** | Conventional Vite/React stack; matches existing `eslint` script |
| Format scope | **Lint + format** | Normalizes the whole repo; one-time large diff accepted |

`uv` is available on PATH (use `uvx pre-commit`); Node 22 / npm 10 are available.

---

## Affected files

- `.pre-commit-config.yaml` *(new)* — three hook groups:
  - `pre-commit/pre-commit-hooks`: `trailing-whitespace`, `end-of-file-fixer`,
    `check-yaml`, `check-toml`, `check-merge-conflict`,
    `check-added-large-files`, `mixed-line-ending`.
  - `astral-sh/ruff-pre-commit`: `ruff` (`check --fix`) + `ruff-format`, scoped
    `files: ^src/backend/`.
  - `repo: local` hooks `frontend-eslint` and `frontend-prettier` scoped
    `^src/frontend/`, delegating to the frontend's own npm scripts
    (`language: system`, `pass_filenames: false`) so tool versions stay pinned
    in `package.json`.
- `src/backend/pyproject.toml` — add `[tool.ruff]`: `target-version = "py312"`,
  `line-length = 88`, `[tool.ruff.lint] select = ["E","F","I","UP","B"]`,
  relax/ignore autogenerated `alembic/versions` where needed.
- `src/frontend/eslint.config.js` *(new)* — flat config using `@eslint/js`,
  `typescript-eslint`, `eslint-plugin-react-hooks`,
  `eslint-plugin-react-refresh`, `eslint-config-prettier`; ignores
  `dist`/`node_modules`.
- `src/frontend/.prettierrc.json` *(new)* — `singleQuote: true`, `semi: false`
  to match existing code style (see `src/frontend/src/main.tsx`); plus
  `src/frontend/.prettierignore`.
- `src/frontend/package.json` — add devDeps (`eslint`, `@eslint/js`,
  `typescript-eslint`, `eslint-plugin-react-hooks`,
  `eslint-plugin-react-refresh`, `globals`, `prettier`,
  `eslint-config-prettier`); add `"format": "prettier --write ."`; keep existing
  `"lint": "eslint ."`.
- `Makefile` — add `lint` (`uvx pre-commit run --all-files`) and `install-hooks`
  (`uvx pre-commit install`) targets under a new section.
- `AGENTS.md` — add a short "Linting & pre-commit" section (setup + usage).

---

## Verification

1. `cd src/frontend && npm install` — installs the new eslint/prettier devDeps.
2. `uvx pre-commit run --all-files` — first run auto-formats the whole repo
   (large one-time diff) and surfaces lint findings; fix remaining errors until
   the run is green.
3. Spot-check each tool independently:
   - `cd src/backend && uvx ruff check . && uvx ruff format --check .`
   - `cd src/frontend && npm run lint && npx prettier --check .`
4. `make lint` runs clean end-to-end.
5. Reformatted files + all config land in the `feat:` commit.
